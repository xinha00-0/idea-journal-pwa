想法记录工具 - 整体架构设计

基于PWA的渐进式Web应用架构

应用架构概览

前端层（用户界面）

主界面

想法列表、快速记录、搜索

编辑界面

Markdown编辑器、图片上传、标签管理

回顾界面

周报生成、历史浏览、筛选查看

统计界面

热力图、主题分析、数据可视化

业务逻辑层

想法管理

CRUD操作、Markdown解析

图片处理

压缩、存储、Base64编码

标签系统

分类管理、标签关联

周报生成

按周统计、摘要提取

热力图计算

频率统计、主题分布

数据层（本地存储）

IndexedDB

主要数据库：想法、标签、分类

LocalStorage

用户设置、应用配置

文件系统API

图片文件、备份文件

基础设施

Service Worker

离线缓存、后台同步

Manifest.json

应用安装、图标配置

响应式设计

适配手机屏幕

技术栈选择

前端框架: 使用原生HTML/CSS/JavaScript，无需框架，保持简单

Markdown编辑器: 使用现成的编辑器库（如EasyMDE或SimpleMDE）

图片压缩: 使用Canvas API进行客户端压缩

数据可视化: 使用Chart.js绘制热力图和统计图表

数据存储: IndexedDB作为主要数据库，localStorage存储配置

数据流设计

用户创建想法 → Markdown编辑器 → 图片压缩上传 → 添加标签 → 保存到IndexedDB → 生成周报 → 计算热力图 → 数据可视化展示

用户导出数据 → 生成JSON/Markdown文件 → 下载到本地 → 可导入到其他设备
