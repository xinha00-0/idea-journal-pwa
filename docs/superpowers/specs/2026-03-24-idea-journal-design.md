# 安卓想法记录工具 - 设计文档

## 1. 项目概述

### 1.1 项目名称
想法记录 (Idea Journal)

### 1.2 项目目标
开发一款基于PWA的安卓想法记录工具，用于个人日常想法快速记录，支持Markdown编辑、图片压缩、标签分类、按周回顾和热力图可视化。

### 1.3 目标用户
个人用户，无安卓开发经验，需要简洁、高效的想法记录工具。

### 1.4 核心价值
- **快速记录**：随时随地捕捉想法
- **智能回顾**：按周生成总结报告
- **数据可视化**：通过热力图了解记录习惯
- **轻量级**：节省设备资源，快速响应

## 2. 需求总结

### 2.1 功能需求
1. **想法记录**
   - Markdown编辑器（支持标题、列表、粗体、斜体、链接、图片）
   - 图片上传与自动压缩
   - 标签/分类管理
   - 自动保存草稿

2. **回顾功能**
   - 每周自动生成想法总结报告
   - 按周筛选查看历史想法
   - 关键词提取和摘要生成

3. **热力图功能**
   - GitHub风格的频率热力图
   - 主题分布热力图
   - 交互式查看详情

4. **数据管理**
   - 本地存储（IndexedDB）
   - JSON格式导入/导出
   - Markdown格式导出
   - 数据备份与恢复

### 2.2 非功能需求
1. **性能**：页面加载 < 2秒，内存占用 < 50MB
2. **兼容性**：Android 8.0+，支持320px-414px屏幕宽度
3. **离线功能**：完全支持离线使用
4. **设计**：极简主义，节省空间，响应式设计

## 3. 技术架构

### 3.1 技术栈
- **前端**：原生HTML/CSS/JavaScript
- **CSS框架**：Tailwind CSS
- **图标**：Material Symbols
- **字体**：Manrope (标题) + Inter (正文)
- **Markdown编辑器**：EasyMDE/SimpleMDE
- **图表库**：Chart.js（用于热力图）
- **存储**：IndexedDB + LocalStorage

### 3.2 应用架构
```
┌─────────────────────────────────────┐
│           前端层 (UI)                │
├─────────────────────────────────────┤
│ 主界面 │ 编辑界面 │ 回顾界面 │ 统计界面 │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│         业务逻辑层                   │
├─────────────────────────────────────┤
│ 想法管理 │ 图片处理 │ 标签系统 │ 周报生成 │
└─────────────────────────────────────┘
                ↓
┌─────────────────────────────────────┐
│           数据层                    │
├─────────────────────────────────────┤
│   IndexedDB    │    LocalStorage    │
└─────────────────────────────────────┘
```

### 3.3 PWA配置
- **Manifest.json**：应用名称、图标、主题色
- **Service Worker**：离线缓存、后台同步
- **响应式设计**：适配不同屏幕尺寸

## 4. 设计规范

### 4.1 设计系统
基于"The Digital Vellum"设计风格，强调：
- **极简主义**：减少视觉元素，专注内容
- **呼吸感**：大量负空间，内容有呼吸空间
- **编辑感**：不对称布局，高端文具感觉

### 4.2 颜色方案
```css
/* 主色系 */
primary: #006e1c (深森林绿)
secondary: #0061a4 (深蓝色)

/* 表面色系 */
surface: #fbf9f8 (基础背景)
surface_container_low: #f6f3f2 (次要区域)
surface_container_lowest: #ffffff (卡片背景)
surface_container_highest: #e4e2e1 (浮动元素)

/* 文字色 */
on-surface: #1b1c1c (主要文字)
on-surface-variant: #3f4a3c (次要文字)
```

### 4.3 字体规范
- **标题 (Manrope)**：display-md (2.75rem) - 大胆自信
- **正文 (Inter)**：body-lg (1rem)，行高1.6 - 确保可读性
- **标签 (Inter)**：label-md (0.75rem)，字距0.05rem - 元数据感觉

### 4.4 间距规范
```css
/* 间距比例 */
spacing-1: 0.25rem (4px)
spacing-2: 0.5rem (8px)
spacing-4: 1rem (16px)
spacing-6: 1.5rem (24px)
spacing-8: 2rem (32px)
spacing-16: 4rem (64px)
```

### 4.5 组件设计
1. **按钮**
   - 主要按钮：绿色渐变背景，圆角md
   - 次要按钮：无背景，绿色文字

2. **想法卡片**
   - 背景：surface_container_lowest
   - 圆角：lg (0.5rem)
   - 内边距：16px (上下) / 8px (左右)
   - 卡片间距：spacing-6 (24px)

3. **标签 (Chips)**
   - 背景：surface_container_high
   - 圆角：full
   - 选中状态：secondary_container背景

4. **输入框**
   - 无边框，极简设计
   - 焦点状态：背景变化
   - 字体大小：title-lg (1.375rem)

## 5. 数据模型

### 5.1 想法数据结构
```javascript
{
  "id": "string",           // UUID
  "title": "string",        // 想法标题
  "content": "string",      // Markdown内容
  "images": ["string"],     // Base64编码的图片数组
  "tags": ["string"],       // 标签ID数组
  "category": "string",     // 分类ID
  "created": "timestamp",   // 创建时间
  "updated": "timestamp",   // 最后更新时间
  "wordCount": "number",    // 字符数
  "isPinned": "boolean"     // 是否置顶
}
```

### 5.2 标签数据结构
```javascript
{
  "id": "string",           // UUID
  "name": "string",         // 标签名称
  "color": "#hex",          // 标签颜色
  "count": "number",        // 使用次数
  "created": "timestamp"    // 创建时间
}
```

### 5.3 分类数据结构
```javascript
{
  "id": "string",           // UUID
  "name": "string",         // 分类名称
  "icon": "string",         // Material图标名称
  "color": "#hex",          // 分类颜色
  "order": "number"         // 排序顺序
}
```

### 5.4 数据库表设计
```
IndexedDB:
├── ideas (想法表)
├── tags (标签表)
├── categories (分类表)
└── weekly_reports (周报表)

LocalStorage:
├── user_settings (用户设置)
├── app_config (应用配置)
└── last_backup (最后备份时间)
```
